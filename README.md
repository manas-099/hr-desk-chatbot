
# HR Policy Desk

A guardrailed RAG chatbot built with NeMo Guardrails for **Quilltony Technologies**,
answering employee HR questions (PTO, benefits, compensation bands, tuition) from a
fixed internal knowledge base — with fact-checking, PII masking, jailbreak detection,
and harassment-report escalation enforced at every stage of the pipeline.

## What this is

- **RAG**: retrieves grounded answers from `guardrails/kb/*.md` (converted from real
  PDFs via Docling)
- **Guardrails**: NeMo Guardrails wraps that retrieval with input/dialog/retrieval/
  output rails — blocking PII leakage, hallucinated policy answers, jailbreaks, and
  routing harassment reports straight to an anonymous ticket instead of the LLM

## Project structure

```
backend/
├── app/
│   ├── core/           # config.py (model config), logging.py (audit trail)
│   ├── llm/            # HTTP LLM wrapper + factory (self-hosted / OpenRouter / OpenAI)
│   ├── services/       # chat_service.py — wires NeMo Guardrails into FastAPI
│   ├── rag/            # ingest_pdf.py — Docling PDF -> markdown, one-time/on-update
│   └── main.py
│
├── guardrails/          # NeMo Guardrails config root
│   ├── config.yml       # model definitions + rail flow wiring
│   ├── prompts.yml       # self-check-facts / self-check-input prompts
│   ├── actions.py       # Python functions backing .co `execute` calls
│   ├── rails/*.co       # input/dialog/retrieval/output flows
│   └── kb/*.md          # knowledge base — generated by ingest_pdf.py, read by NeMo
│
├── scripts/
│   └── generate_guardrails_config.py   # rebuilds guardrails/*.yml and *.co from scratch
│
├── tests/
│   └── test_retrieval_smoke.py   # end-to-end smoke test through the full rails pipeline
│
└── .env                 # secrets — never committed

```

## Setup

```bash
python -m venv hr_env
hr_env\Scripts\activate          # Windows
pip install -r requirements.txt
```

Create `.env` in `backend/`:
```
OPENAI_API_KEY=sk-...
OPENROUTER_API_KEY=sk-or-...
SELF_HOSTED_API_URL=http://localhost:8000/v1
SELF_HOSTED_AUTH_TOKEN=...
```

## Build the knowledge base

Convert source PDFs into the markdown NeMo actually reads:
```bash
python -m app.rag.ingest_pdf
```

## Generate/reset guardrails config

```bash
python -m scripts.generate_guardrails_config
```

## Run the smoke test

```bash
python -m tests.test_retrieval_smoke
```
